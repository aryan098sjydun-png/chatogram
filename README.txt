چتوگرام - نسخه بدون ماژول native

این نسخه برای Termux ساخته شده و دیگر از better-sqlite3 استفاده نمی‌کند؛ اطلاعات کاربران در data.json ذخیره می‌شود.

اجرا:
1) وارد پوشه پروژه شوید:
   cd ~/storage/downloads/chatogram_no_native

2) نصب وابستگی‌ها:
   npm install

3) اجرا:
   npm start

4) مرورگر:
   http://127.0.0.1:3000

امکانات:
- ثبت‌نام و ورود با نام کاربری و رمز عبور
- خروج از حساب
- پروفایل، جنسیت، شهر و عکس پروفایل
- نمایش کاربران آنلاین
- پیدا کردن هم‌صحبت بر اساس جنسیت
- چت لحظه‌ای
- رفتن به نفر بعد
- گزارش کاربر
- ذخیره اطلاعات در data.json
